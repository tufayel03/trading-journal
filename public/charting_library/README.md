# TradingView Advanced Charts Library Directory

Place your official TradingView Charting Library files in this folder (`public/charting_library/`).

### Required Files:
1. `charting_library.standalone.js` (or `charting_library.js`)
2. `bundles/` folder (containing CSS files, JS bundles, and locale chunks)

Once you copy these files here, the Trade Replay Studio will automatically detect and initialize the official TradingView chart engine with 100+ native drawing tools, 0 scroll lag, and full 60fps canvas performance!
